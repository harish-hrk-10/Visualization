# Superstore Sales Data Analysis

## Project Overview

This project analyzes a Superstore sales dataset using Python, Pandas, Matplotlib, and Seaborn.

The main purpose is to clean the data, perform basic analysis, and visualize sales and profit information.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

The following tasks were completed:

1. Explored the dataset.
2. Created a bar plot to show total sales for each category.
3. Created a box plot to visualize profit distribution.
4. Created a scatter plot between discount and profit.
5. Created a correlation matrix for numerical columns.
6. Identified the category with the highest total profit.

## Business Insights

### 1. Technology has the highest total profit

Technology generated the highest total profit among the three categories, with approximately **903.60** in profit.

### 2. Furniture has a negative total profit

Furniture had a total profit of approximately **-1677.41**, indicating that this category resulted in an overall loss in the dataset.

### 3. Office Supplies generated a positive profit

Office Supplies generated approximately **671.92** in total profit, making it the second most profitable category.

## Conclusion

The analysis shows that **Technology is the most profitable category**, while **Furniture requires further investigation** because it generated an overall loss. The visualizations also help understand the relationship between sales, discounts, and profits.
